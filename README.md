# 💬 빠른 메모 (quick-memo)

카톡 **'나에게 쓰기'** 대신 쓰는 **채팅형 초고속 메모 웹앱**. 열자마자 입력창이 있고, 톡 치고 Enter를 누르면 날짜·시간이 찍혀서 쌓입니다.
**모든 데이터는 이 브라우저 안(IndexedDB/LocalStorage)에만 저장되고 서버로 전송되지 않습니다.**

- 실행: <https://anchirong9-arch.github.io/quick-memo/>
- 폰에서 **홈 화면에 추가**하면 앱처럼 전체 화면으로 열립니다(PWA·오프라인 지원).

## 기능

| 구분 | 내용 |
| --- | --- |
| 입력 | 하단 고정 입력창 · Enter 전송 / Shift+Enter 줄바꿈 · **↵ 버튼**으로 줄바꿈(모바일도 터치 한 번) · 입력한 줄바꿈(빈 줄 포함)은 그대로 보존 · 자동 높이 조절 · 날짜 구분선 · 시간 표시 |
| 검색 | 상단 고정 검색바 · 입력 즉시 실시간 필터 · 단어별 노란/보라 하이라이트 · 결과 개수(`N개 일치`) |
| 필터 | `전체` `📌 고정` `🔗 링크` `🖼️ 사진` `☑️ 할일` + 본문 `#태그` 클릭 시 그 태그만 |
| 편의 | 링크 자동 감지(도메인 카드) · 원탭 복사 · 상단 핀 고정 · 할일 체크(`- [ ]`) · 사진 첨부(자동 리사이즈) · 메모 합치기 · 수정 · 삭제(휴지통+실행취소, 30일 뒤 자동 정리) |
| 할일 | 입력창 **☑️** = 지금 쓴 여러 줄을 **줄마다 체크박스**로 한 번에 변환(빈 줄은 목록에서 빠지고, 이미 만든 체크는 상태 유지, 되돌리기 가능) · 메모 카드 `⋯` → **☑️ 할일** 로 나중에도 한 번에 변환 · 네모는 각 줄 글자 맨 앞에 붙고 **줄마다 따로 체크/해제** · `☑️ 할일` 필터 |
| 합치기 | 상단 **⇅ 합치기** → 카드 탭으로 여러 개 선택 → **선택한 N개 합치기** · 시간순으로 `\n\n` 연결(전부 할일 메모면 빈 줄 없이 `\n`로 이어 하나의 체크리스트), 사진은 모아서 함께 첨부 · 원본 삭제(휴지통) 기본/해제 가능 · 합친 메모로 스크롤·강조 · 실행취소 |
| 백업 | JSON 내보내기 / 가져오기 (메모 + 사진 포함, 중복은 건너뜀) |
| 테마 | 다크(기본) ↔ 라이트 전환, 설정 저장 |
| PWA | 매니페스트·아이콘·서비스워커로 홈 화면 추가·오프라인 실행 |

## 구조

```
index.html            화면 뼈대
styles.css            다크/라이트 테마, 채팅 버블 UI
app.js                저장소(IndexedDB) · 검색/하이라이트 · 입력 · 백업 로직
manifest.webmanifest  PWA 설정
sw.js                 앱 셸 오프라인 캐시
icons/                앱 아이콘 (192·512·maskable·apple-touch)
```

## 단축키

- `Ctrl/⌘ + K` — 검색창으로 이동
- `Enter` — 전송 · `Shift + Enter` — 줄바꿈 · `↵` 버튼 — 줄바꿈 · `Esc` — 검색/수정/선택 취소

## 참고

- 브라우저 데이터를 지우면 메모도 함께 지워지므로, 가끔 **더보기 → JSON 백업 내보내기**로 백업하세요.
- 백업 파일을 **가져오기** 하면 다른 기기·브라우저에도 그대로 옮길 수 있습니다.
